# SECCA identity

SECCA means **Solid-model Evaluation of CAD Construction Agents**. The Japanese name is 雪華, read せっか (sekka).

The original SVG mark combines six snow-crystal arms with an isometric solid. It uses flat geometry, a dark blue outline, and a teal accent. The mark and header contain no third-party logo or embedded font.

| Asset | Use |
| --- | --- |
| `secca-mark.svg` | Site logo and favicon |
| `secca-header.svg` | Repository header |

Keep clear space around the mark and preserve its proportions. Use the unmodified files on white or pale backgrounds. The header includes accessible title and description elements. The project license applies to this original artwork, subject to its stated exclusions for benchmark data.
