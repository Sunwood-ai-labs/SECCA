# 来歴と権利

コード、固定入力、旧基準例、公開実験の出典と限界を残します。SECCAという公開名は、ベンチマークのすべてのファイルの利用権を与えるものではありません。

## コードとオリジナルロゴ

プロジェクトコードとオリジナルのSECCAロゴには、除外事項を含む[リポジトリのライセンス](https://github.com/Sunwood-ai-labs/SECCA/blob/main/LICENSE)が適用されます。雪の結晶とCAD立体のSVGは、このプロジェクト向けに作成しました。第三者のブランドロゴは含みません。

同梱FreeCAD MCPには[MITライセンス](https://github.com/Sunwood-ai-labs/SECCA/blob/main/container/vendor/freecad-mcp/LICENSE)と[ソースmanifest](https://github.com/Sunwood-ai-labs/SECCA/blob/main/container/vendor/source-manifest.json)を残しています。コンテナへ導入するFreeCADや依存先にも、それぞれのライセンスがあります。プロジェクトのライセンスがそれらを置き換えるわけではありません。

## 参照画像とCADデータ

参照画像はユーザー提供のスクリーンショットです。元の出典、作者、ライセンスは記録されていません。コードのMITライセンスから、画像や描かれたデザインの利用・再配布許諾を推定しないでください。生成CADと描画画像も、そのデザインの権利を確定しません。[データ来歴](https://github.com/Sunwood-ai-labs/SECCA/blob/main/NOTICE.md)にリポジトリの注意事項を記載しています。

固定プロトコルとmanifestに画像のSHA-256を残しています。このハッシュは使用したバイト列を特定するもので、所有権やライセンスの根拠ではありません。

## 旧基準例

`assets/baseline/` は、Windowsホストで実行した `opencode/glm-5.3-flash-free` の1試行です。原採点43点は、モデル名を知るコーディネータ45点と独立42点・42点の項目別中央値で集計しています。Podmanで生成した基準例でも、3件すべてを盲検にした評価でもありません。

オフラインの再検査は、保存済みCADを記録したランタイムで開いて描画できることを示します。モデルが再生成したことは示しません。旧採点は次のコマンドで再計算できます。

```sh
uv run --frozen python scripts/scores.py verify-baseline
```

## Beam公開実験

[実験の公開版](https://github.com/Sunwood-ai-labs/SECCA/tree/main/experiments/beam-free-20261017)に、レポート、採点済みCAD、描画画像、採点根拠、実行イベント、選択した実行記録を保存しています。export manifestには公開ファイルのハッシュと、元記録から公開版への変換を記録しています。管理記録を移植可能な形にしたコピーの照合時は、その注意事項も確認してください。

BeamのランタイムIDとモデルカタログの出典は、その実験のものです。旧ランタイム検証記録や後から構築した公開用ランタイムとは、イメージIDが異なる場合があります。主張は対応する記録と照合してください。

## 再現できる範囲

構築手順は主要な版とベースイメージのdigestを固定し、パッケージ状態、入力、解決したイメージIDを記録します。一方、外部依存先の取得可否、提供元の動作、サービス負荷、評価条件には統制できない部分があります。再現時はOCIイメージと原記録を保存してください。依頼文を固定しただけでは、モデル出力や描画画像のバイト一致は保証できません。
