# 固定プロトコル

正本は [`assets/protocol.json`](https://github.com/Sunwood-ai-labs/SECCA/blob/main/assets/protocol.json) です。IDは `racing-kart-image-v2-podman`、版は `2.0`、固定日は2026-10-17です。SECCAという公開名に変えても、識別子と固定資産のバイト列は変えません。

## 候補への入力

候補には元画像と、次の日本語依頼文を渡します。

> 添付画像のレーシングカートをFreeCAD MCPで作成し、racing-kart.FCStdとracing-kart.stepに保存してください。

出力は `racing-kart.FCStd` と `racing-kart.step` です。参照画像、依頼文、配点、描画条件のSHA-256を記録しています。`candidate.py verify-assets` でmanifestの全項目を検査できます。

候補には配点、旧CAD、過去の結果、採点資料、管理用スキルを渡しません。汎用のランタイム指示と、選択したモデルの設定は実行環境に含まれます。

## 実行条件

| 設定 | 固定条件 |
| --- | --- |
| エージェント | OpenCode 1.19.3、`run --pure`、選択モデル |
| CAD | Xvfb上のFreeCAD GUI、stdioのFreeCAD MCP |
| 試行上限 | 標準1,800秒 |
| モデルの置換 | 無料から有料への切替を含め、自動変更なし |
| 候補の環境 | 新しい作業領域・ホーム・文書・試行専用APIソケット |
| 生成の範囲 | Podman Linux、ネットワーク `none`、ホストCADへの接続なし |
| temperature・seed | 提供元の既定値と未指定。変更時や取得可能な場合は記録 |

API拒否やCAD未生成も観測した結果です。手動の再実行は別試行にします。モデル内部のツール再試行は同じ試行に含み、生成時間にも含めます。

## 描画条件

[`assets/render-spec.json`](https://github.com/Sunwood-ai-labs/SECCA/blob/main/assets/render-spec.json) に、正投影、白背景、Flat Lines表示、元の色と表示状態、カメラのクォータニオンを固定しています。

| 方向 | サイズ |
| --- | --- |
| 斜視 | 1600 × 1000 |
| 上面 | 1280 × 900 |
| 右面 | 1280 × 900 |
| 斜視から作るプレビュー | 960 × 600 |

描画には `fitAll` を使います。見栄えのよいカメラを選ぶために形状を回転・移動してはいけません。追加画像は別名で保存し、変換条件を記録してください。描画時に元文書を保存し直しません。FreeCAD、Qt、GPU、ドライバーが異なる環境間で、PNGのバイト一致は保証しません。

## 比較できる範囲

入力、ツール、イメージ、描画条件、配点の変更はプロトコル差分です。条件差を残し、異なる結果を混ぜないでください。提供元の確率的な出力とサービス負荷は統制していません。

配点は旧基準例の生成後、数値採点の前に設計し、その後のモデル実行前に固定しました。Windowsホスト版の43点はv2 Podman環境より前の記録です。厳密な比較には、同じランタイムと評価者設定による再生成・再評価が必要です。
