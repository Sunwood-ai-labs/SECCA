# 隔離

エージェント、FreeCAD GUI、FreeCAD MCPを、試行専用のコンテナへまとめて入れます。エージェントだけをコンテナに入れても、FreeCADの任意Python実行からホストへアクセスできる余地が残るためです。

## 候補の実行範囲

| 制御 | 設定 |
| --- | --- |
| ネットワーク | `none` |
| ユーザー | UID 10000 |
| ルートファイルシステム | 読み取り専用 |
| Linux capability | すべて削除 |
| 権限昇格 | `no-new-privileges` |
| ホストのbind mount | なし |
| 公開ポート・管理ソケット | なし |
| 状態 | 試行ごとに新しい作業領域・ホーム・FreeCAD文書・APIソケット |

元画像と選択した実行用入力だけを候補へコピーします。過去のCAD、採点資料、ホスト設定、他試行は渡しません。ランタイムの構築に含めるのは汎用起動コードとMCPソースであり、採点用資産は含めません。

## API通信

候補のループバックHTTPをアダプターで受け、試行専用Unixソケットへ接続します。別のゲートウェイは、固定の公開HTTPS APIに対して、記録したモデルの推論POSTだけを許可します。

任意の接続先、CONNECT、リダイレクト、プライベートIP、別モデル、提供側の履歴・ファイル参照、Web検索を拒否します。ソケット用ボリュームは読み取り専用マウントでも接続できるため、要求はゲートウェイで検査します。API認証情報を持つのはゲートウェイであり、候補ではありません。

## 後処理の範囲

候補を停止してからCADを回収します。検査と描画は、推論ソケットを持たない新しい `network none` コンテナで実行します。元ファイルと結果のハッシュを記録し、表示条件を変えた後も元CADを保存し直しません。

## 検証と限界

2026-10-17の旧[ランタイム検証記録](https://github.com/Sunwood-ai-labs/SECCA/blob/main/references/verified-runtime.json)と根拠を保存しています。この記録では隔離確認19項目、LinuxのUnixソケット、起動、保存CADの再検査、失敗経路を、**新しいモデル推論なし**で検証しています。そこにあるイメージIDは当該記録のもので、後から作ったすべてのランタイムを示すものではありません。

[現行ランタイムの検証手順](https://github.com/Sunwood-ai-labs/SECCA/blob/main/references/runtime.md)には、ソース照合、単体テスト、実FreeCADでの再検査を記載しています。[公開版の検証記録](https://github.com/Sunwood-ai-labs/SECCA/blob/main/references/release-verification.json)で、検証した公開用イメージを特定できます。使用するイメージのIDと実際の検証結果を残してください。Beam実験には、これとは別に実APIを呼んだ記録があります。

検証が示すのは、記録した条件で観測した動作です。あらゆる脱出や可用性攻撃を防ぐ証明ではありません。候補の標準出力、キュー、ログ、ボリュームのディスク消費について、完全な割当制限を検証したものではありません。「絶対に安全」とは表現しないでください。
